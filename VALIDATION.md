## Найденные и исправленные технические проблемы

1. alphaTab автоматически регистрирует listener Web Worker. Сообщение без `cmd` вызывало `Cannot read properties of undefined (reading 'startsWith')`, React показывал ошибку обработки. Добавлен `cmd: 'converter'`. После исправления оба E2E-прогона прошли. Не установлено, что именно эту проблему видел пользователь: нужна проверка его конкретной сборки/окна.
2. alphaTab `MidiFile.events` для MultiTrack имеет рекурсивную ошибку в 1.8.4. Аудиосинтез использует штатный single-track внутренний поток событий; скачиваемый MIDI остаётся format 1.
3. Транспонирование для audio-export применяется один раз: генератор с `applyTranspositionPitches=false`, карта транспонирования передаётся exporter, как в официальном API.
4. GP-каналы > 15 при сериализации MIDI усекались до четырёх бит, создавая конфликты инструментов. Назначены уникальные пары мелодических каналов; ударные на канале 10. Ограничение 7 мелодических партий явно выдаёт ошибку вместо потери резервного канала.
